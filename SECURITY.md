# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Twin Studio, please report it responsibly.

- Email: hello@thesocialtwin.com
- Do not open a public GitHub issue for security vulnerabilities

## Response Time

We acknowledge security reports within 48 hours and aim to provide a fix or mitigation within 7 days.

## Scope

This security policy applies to the Twin Studio desktop application and its install scripts. It does not apply to the web platform (thesocialtwin.com) which has its own security policy.
